# 🕯️ Candila — WDF Final Project

A responsive and brand-focused landing page for **Candila**, a candle brand, developed as the **Final Project of the Web Development Fundamentals (WDF) Camp** at the **School of Artificial Intelligence and Technology (SAIT)**.

> **Candila is a brand presentation landing page, not an online store.**

The main goal of the project is to introduce the Candila brand, showcase its candle products, share customer reviews, and highlight media content through a cohesive and engaging web experience.

---

## 📌 Project Overview

**Candila** is a candle brand landing page designed to communicate the brand's identity and showcase its products in a visually appealing way.

The project brings together the web development concepts learned throughout the WDF Camp and applies them in one complete frontend project.

The landing page focuses on:

* Introducing the Candila brand
* Presenting the brand identity
* Showcasing candle products
* Displaying customer reviews
* Highlighting candle-making content
* Providing a newsletter subscription form
* Creating a responsive experience across different screen sizes
* Adding interactive functionality using JavaScript

---

## 🎓 Project Context

This project was developed as the **Final Project for the Web Development Fundamentals (WDF) Camp** at the **School of Artificial Intelligence and Technology (SAIT)**.

It represents the practical application of the concepts and techniques learned throughout the training.

---

## ✨ Main Sections

The Candila landing page is organized into several main sections:

### 🦸 Hero Section

The main introduction area of the website, designed to present the Candila brand and create a strong first impression.

### 🕯️ Intro / About

Introduces the brand and communicates its identity and concept.

### 🛍️ Our Candles

A product showcase section presenting Candila's candle collection.

### ⭐ Reviews

A customer review section designed to highlight customer experiences and build trust around the brand.

### 🎥 Candle-Making / Video Section

A media section featuring candle-making content using visual and video elements.

### 📩 Newsletter Subscription

A subscription form that allows visitors to enter their information and subscribe to the newsletter.

### 🦶 Footer

The final section of the page containing additional brand information and navigation elements.

## 🛠️ Technologies Used

### HTML5

Used to create the semantic structure and content of the landing page.

### CSS3

Used for:

* Page styling
* Layouts
* Flexbox
* Responsive design
* Media queries
* Visual effects
* Typography
* Spacing
* Component styling

### JavaScript

Used to add interactivity and dynamic behavior to the landing page.

JavaScript is also used for handling user interactions and newsletter form validation.

---

## 💻 Development Techniques

### Semantic HTML

Semantic HTML elements were used to create a structured and meaningful webpage layout.

### Responsive Web Design

The website was designed to provide a consistent experience across different screen sizes.

Responsive behavior was implemented using:

* CSS Flexbox
* Media Queries
* Flexible layouts

### BEM Methodology

CSS classes were organized using the **BEM (Block Element Modifier)** methodology to make the stylesheet more structured, readable, and maintainable.

### JavaScript Interactivity

JavaScript was used to add interactive behavior to the website and improve the overall user experience.

### Form Validation

The newsletter subscription form includes validation to handle user input and provide a better interaction experience.

---

## 📱 Responsive Design

Candila was designed with responsive web development principles in mind.

The layout adapts to different screen sizes, including:

* 💻 Desktop
* 💻 Laptop
* 📱 Tablet
* 📱 Mobile

Flexbox and CSS media queries were used to create responsive layouts.

## 🎨 Design Approach

Candila was designed as a **brand-focused landing page rather than an e-commerce website**.

The goal was to create a visual brand presentation that allows visitors to:

1. Discover the Candila brand
2. Learn about the brand concept
3. Explore the candle collection
4. Read customer reviews
5. Watch candle-making content
6. Subscribe to the newsletter

The design combines product imagery, brand-focused content, customer reviews, and multimedia elements into one cohesive landing page.
